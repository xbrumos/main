# Churro Tycoon

Un minijuego idle/tycoon para móvil y web donde gestionas tu propia churrería. Está construido con HTML, CSS y JavaScript plano para que puedas ejecutarlo rápido en cualquier navegador.

## Cómo ejecutar

1. Sitúate en la carpeta del proyecto y levanta un servidor estático (por ejemplo con Python):

   ```bash
   python -m http.server 4173
   ```

2. Abre `http://localhost:4173` en tu navegador móvil o de escritorio.

El progreso se guarda automáticamente en `localStorage`.
